# Motion and Interaction

- Motion should explain hierarchy or process, not decorate every pixel.
- Use subtle opacity, transform, clip, and scale transitions for entrances and state changes.
- Create one signature interaction for the Thangka studio: a blank canvas progressing through grid, drawing, colour, shading, detail, and completion.
- Keep interaction responsive and interruptible.
- Avoid scroll hijacking and excessive parallax.
- Respect `prefers-reduced-motion` with a useful static experience.
- Animate only transform and opacity when possible.
- Provide hover, focus, active, and touch states for interactive elements.
