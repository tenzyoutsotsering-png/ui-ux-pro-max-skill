# Cultural Frontend Design

Build a premium editorial experience, not a template.

- Use the artwork and photography as the primary visual system.
- Combine restrained contemporary editorial design with authentic Tibetan visual references: manuscript proportions, textile geometry, painted borders, mineral pigments, woodblock textures, monastery architecture, and Tibetan typography where appropriate.
- Avoid decorative overload, fake spirituality, generic lotus/Buddha imagery, excessive gold gradients, and tourist-brochure styling.
- Establish a clear design system before implementation: type scale, spacing scale, color tokens, borders, radii, shadows, image ratios, and interaction states.
- Prefer large visual moments, asymmetric editorial composition, generous whitespace, thin rules, and strong hierarchy.
- Every section must have a purpose and a clear reading order.
- Make mobile composition intentional rather than merely stacking desktop columns.
