# SEO

- Give every important route a unique title and description.
- Use descriptive URLs for courses, workshops, teachers, gallery, journal, and contact pages.
- Add canonical metadata, Open Graph images, sitemap, and robots configuration.
- Use JSON-LD only when it accurately represents the page, such as Organization, Course, Article, BreadcrumbList, and LocalBusiness when applicable.
- Build internal links around real user journeys: tradition → courses → teacher → enrolment.
- Write specific, human-first copy about Tibetan art, techniques, lineage, teachers, and learning outcomes.
- Never keyword-stuff cultural or historical claims. Verify factual claims and names.
