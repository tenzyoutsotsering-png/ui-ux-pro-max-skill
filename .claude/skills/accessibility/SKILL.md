# Accessibility

- Use semantic HTML before ARIA.
- Every interactive element must be keyboard reachable and have a visible focus state.
- Give images meaningful alt text when informative and empty alt text when decorative.
- Maintain readable contrast and do not communicate meaning by color alone.
- Use labels and clear error messages for forms.
- Respect reduced-motion preferences.
- Keep heading hierarchy logical.
- Ensure menus, dialogs, galleries, carousels, and accordions have usable keyboard behavior.
- Test at narrow widths, zoomed text, keyboard-only navigation, and reduced motion.
