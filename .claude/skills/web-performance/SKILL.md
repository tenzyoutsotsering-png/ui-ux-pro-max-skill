# Web Performance

- Treat high-resolution artwork photography as a performance risk.
- Use responsive image dimensions, modern formats, lazy loading below the fold, and priority loading only for the primary hero image.
- Prevent layout shift with known image aspect ratios and font strategy.
- Keep client JavaScript minimal and avoid animation libraries when CSS or native browser APIs are sufficient.
- Lazy-load non-critical sections and embeds.
- Review bundle size before adding dependencies.
- Check LCP, CLS, INP, mobile performance, and slow-network behavior before release.
